# Task execution and owner delivery

Cites [the pinned task journey](../../raw/v1/voice-to-durable.feature), [the task workspace effect](../../raw/v1/task-workspace-effect.py), [the execution contract](../../raw/v1/c8-agent-execution.feature), [the image handoff](../../raw/v1/task-image-ensure.py), [task result delivery](task-result-delivery.md), and [task lifecycle](task-lifecycle.md).

An accepted task has one identity, one owner, one selected workspace, and one instruction. A worker may claim it only after the task authority records dispatch. The worker's attempt can run on the host or in an isolated task environment. Both modes must return the same owner-visible lifecycle, answer, and work product. Progress is bounded and belongs to that task. A lost dispatch acknowledgment or worker exit cannot silently create another attempt. [Task journey, execution contract]

The selected source is prepared before execution. A scratch task starts with its own empty workspace. A repository task starts from a pinned, approved source snapshot in a task-specific workspace. Its source identity survives a restart and remains associated with the final patch. An optional repository-declared execution image must be resolved and verified before the isolated environment starts. A missing image build, source publication, or image installer is an explicit preparation failure; it cannot be represented as a completed task. [Workspace effect, image handoff]

After the worker finishes, the same task workspace is captured before the terminal completion is recorded. The owner receives a bounded answer and exactly the declared work product kind: a patch for a repository task or an archive for a scratch task. A capture failure is terminal execution failure. A later missing download is a retrieval failure and leaves completion intact. A repeat worker callback or late callback cannot replace an existing terminal result. [Task result delivery, task lifecycle]

The owner reads the result and downloads the declared work product through an authenticated task route. A foreign owner receives no task or bytes. A source image or repository publication can depend on external services; local qualification must name whether it exercised a real task process, an isolated environment, the public owner route, and the external source or image handoff. [Task result delivery, execution contract]
