# Slice 21 decisions

Cites the [plan](plan.md), [workbench rules](../../wiki/private-review-workbench.md), [quality decisions](../17-knowledge-quality/decisions.md), [continuity decisions](../18-private-knowledge-continuity/decisions.md), and [pinned review guide](../../../raw/v1/journal-review-mcp-readme.md).

## D88: one place, two decision streams

The owner can navigate quality and metadata review in one place, but each stream keeps its own authority, progress, and gate. A quality label cannot decide a metadata disposition. A metadata exclusion cannot satisfy quality coverage. The pruned branch is a single completion flag for all private knowledge work.

## D89: draft edits do not certify review

Saving a label or family assignment creates a draft or an explicit action, never implicit independent review, privacy approval, or holdout eligibility. A reviewer and, if disputed, a different adjudicator act separately. The pruned branch is upgrading the 120 prepared candidates because their fields were filled in.

## D90: provenance precedes metadata release

A linked resource needs a verified frozen source edge. An excluded record needs an owner decision, reason, and evidence; an unresolved record stays quarantined. Every disposition is retained in accounting. The pruned branch is treating a label or a convenient exclusion toggle as proof of source provenance.

## D91: local review writes require replayable authority

Each action has an identity and expected revision. Ordered decisions drive the current view and survive restart. Private payloads remain restricted and shared events carry only opaque identities and digests. The pruned branch is a mutable review file whose final state cannot explain how a decision was reached.

## D92: gate outputs are deliberately separate

The owner gets a private row-level report and a safe aggregate status for each gate. Ordinary review cannot consume a locked holdout or select live reads. The pruned branch is a generic success badge interpreted as permission to promote a model or switch the live source.
