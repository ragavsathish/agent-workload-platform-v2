# Ticket 02: bounded proposal and owner decision

Cites [slice plan](plan.md), [taxonomy rules](../../wiki/knowledge-taxonomy.md), [source prompts](../../../raw/v1/candidate-prompt.md), and [review rules](../../wiki/personal-knowledge.md).

Accept a bounded proposal only for an admitted owner source and active category version. Require an exact excerpt, stable result identity, model and prompt versions, and a permitted category. Preserve model output and validation outcome. Reconcile same-content replay and refuse changed content under the same identity. Keep timeout and empty results visible. Proposals become pending items; owner acceptance or correction at the current revision is the only publication path. For a proposed subject relation, require two owner-visible endpoints, relation type, source, and a separate owner decision.
