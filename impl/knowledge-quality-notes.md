Cites the [slice plan](../docs/plan/17-knowledge-quality/plan.md), [quality rules](../docs/wiki/knowledge-quality.md), [v1 private review schema](../raw/v1/journal-reviewed-manifest.schema.json), [v1 scorer](../raw/v1/journal-reviewed-eval-lib.mjs), [v2 taxonomy evaluator](src/awp_v2/knowledge/taxonomy_quality.clj), and [v2 native worker evaluator](runtime/products/voice-agent/apps/pi-agent/knowledge-quality.mjs).

## Current evidence and limits

The v1 checked-in classifier fixture has 40 balanced cases and 200 variants but no review, family, or split fields. Two ignored private v1 manifests were inspected only for structure: 80 classifier rows are pending with privacy review pending, and 40 journal rows are pending in development with privacy review pending. Their content and digests are not present here. Neither qualifies the v2 model. The v2 taxonomy evaluator can return passed if callers supply a claimed review flag, matching case IDs, and a digest; it does not independently verify the review ledger, split hygiene, pre-run threshold timestamp, or actual model invocation. The native worker scorer accepts a self-declared `reviewedBy`/`reviewed` corpus and thresholds inside the same file, counts an incorrect exact-evidence category as both an addition and a miss, and has no relation metric. These are protocol scaffolds, not a live quality pass. The bounded ORC LLM path in `orc_adapter.clj` creates private candidates; its local smoke is not a reviewed corpus evaluation.

## Build seam

Keep Grain commands/events as authority for owner source, result, review, and current knowledge. A separate private evaluation ledger should record case eligibility, independent annotation and adjudication, policy freeze, run attempts, and holdout consumption; use stable opaque IDs and digests rather than source text in Grain events where feasible. A read model can materialize readiness and gate state from that ledger. ORC remains a derived graph and candidate producer. Never let evaluator output issue an owner acceptance command.

The private corpus and row-level reports must live outside this repository and use restrictive permissions. Validate a versioned manifest against review records and privacy approval, check semantic-family and normalized duplicate overlap, and require coverage by branch, class, negative slice, and random sample. Do not copy the v1 drafts automatically; a human must adjudicate source and labels. Write a public summary only through a disclosure filter, and omit row IDs, examples, source text, private paths, and private-data digests.

Freeze a policy file and baseline before invoking `processWork` or `run-local-source-bounded!`. Pin model and prompt, category version, worker and scorer digests, corpus/split digest, resource bounds, and rollback candidate. The ORC candidate path and native worker path should be scored separately through their actual production boundaries. For relations, score reviewed endpoint pairs and edge type; for classifications, include `none` and per-class confusion; for journal, use entry matching plus evidence and empty-case metrics. Require all branch gates independently. Stochastic inference needs a declared repeated-run subset; do not repeat the locked holdout. The implementation turn should start with red tests for `quality-001` through `quality-009`, then run the full verifier and clean-room fence.

If reviewed labels remain unavailable, build and verify the readiness refusal and aggregate report, then record `open`. Do not fabricate a reviewed corpus or loosen the policy to obtain a pass. Private migration reconciliation and public tailnet qualification remain separate.

## Built path and current gate

The [quality policy](qualification/knowledge-quality-policy-v1.json) fixes the coverage and numeric gates before a reviewed run. The [private corpus schema](qualification/knowledge-quality-corpus-v2.schema.json) distinguishes pending candidates from reviewed cases. The [Grain knowledge model](src/awp_v2/knowledge/event_model.clj) now carries case metadata, independent review actions, frozen runs, single-use holdout consumption, and outcomes in the same owner-scoped event store as owner knowledge. No case text or individual prediction is stored in these events. The [read model](src/awp_v2/knowledge/read_models.clj) rebuilds review and run state; owner queries remain separate from publication queries.

The [evaluator](runtime/products/voice-agent/apps/pi-agent/knowledge-quality-v2.mjs) checks review/privacy status, exact anchors, family and duplicate separation, coverage, branch-specific errors, and the numeric gate. The [runner](runtime/products/voice-agent/apps/pi-agent/knowledge-quality-run.mjs) selects one frozen partition, checks actual worker/model/prompt/scorer identities and the Grain ledger before inference, and writes row-level observations only to a restricted private file. It invokes the native Effect worker for journal and assertion cases and the bounded [ORC adapter](src/awp_v2/knowledge/quality_orc_runner.clj) for concepts. The current bounded ORC path has no model relation proposal; relation evaluation returns unavailable and cannot pass the quality gate. A holdout run is consumed in Grain and by a private exclusive marker before model calls. The [ledger gate](src/awp_v2/knowledge/quality_ledger_gate.clj) refuses a manifest that lacks matching approved review actions and frozen run digests.

The ignored v1 classifier and journal drafts were inspected for metadata, then 120 pending candidates were prepared into a mode-0600 file outside the repository. A readiness run found **0 eligible cases out of 120**. It is open for pending review and privacy approval, unassigned case fields, and missing coverage. Neither the candidate file nor private row-level results are committed. The [qualification report](qualification/knowledge-quality-report.md) records only safe aggregates and the remaining gates.
