# Slice 12 implementation notes

Cites [slice plan](../docs/plan/12-task-result-delivery/plan.md), [source artifact capture](../raw/v1/task-artifacts.py), [source workspace effect](../raw/v1/task-workspace-effect.py), and [formal contract](../specs/task-result-delivery.allium).

The Effect scheduled worker settles through `capture-complete` rather than publishing raw text as a terminal result. Grain checks that the task is running, captures the selected workspace into a bounded local artifact, and commits a result containing only a SHA-256 digest and byte count for the expected kind. Capture errors settle the task as failed with a bounded public reason. The result stays in the Grain task event history; artifact bytes stay in the task storage directory and survive restart. A failed Grain completion may leave an unreferenced local file, but cannot create a public artifact declaration.

For repository work, capture uses a binary patch against the selected checkout's `HEAD`, including new files. Scratch capture walks regular files without following links, limits file count, total input bytes and archive bytes, and refuses paths outside the workspace. The same 16 MiB read cap applies to stored objects. A read checks size and digest against the Grain declaration. The owner query first loads the task through Grain's owner-scoped query, then selects only the kind allowed by its workspace. Missing, altered, excessive, or incomplete bytes return an explicit lookup failure without changing the completed event.

The private Grain HTTP route returns bytes only after that query. The public gateway checks its configured owner, allows only `patch` or `workspace`, forwards the owner identity, bounds the response, and sets private download headers. It projects answer text and artifact names from the task state and drops raw worker fields and storage metadata. The local public-path test covers both artifact kinds, foreign identity, wrong kind, missing bytes, and a fresh Grain process. Source snapshot publication, task image preparation, external tailnet reachability, and interactive client qualification remain separate boundaries.
